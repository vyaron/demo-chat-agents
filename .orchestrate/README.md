# .orchestrate/

Every file in this directory except this README is **generated by the dev loop**, and none
of it is source of truth. All of it is gitignored (`.orchestrate/*`, with this README
negated), so a run leaves no diff to review. Delete the whole directory to reset a demo —
`dev-loop.js` recreates it on the next run.

| File | Written by | What it is |
|---|---|---|
| `PLAN.md` | `dev-loop.js` | Mirror of the plan for the task currently in flight (the durable copy lives in `.plan/`) |
| `tickets.json` | `dev-loop.js` | Linear ticket ids/urls for the current task |
| `api-contract.yaml` | Frontend Agent | OpenAPI shape a future backend must implement |
| `frontend-agent-report.md` | Frontend Agent | What was built, test results, handoff notes |
| `backend-agent-report.md` | Backend Agent | Only for tasks marked `stack:full` |
| `qa-report.md` | QA Agent | Acceptance criteria PASS/FAIL with evidence |
| `trace.json` | `dev-loop.js` | Per-agent tokens, cost and duration for the last task |
| `trace-live.json` | `trace-agent.js` | Tool-by-tool trace of a single agent run |

Hand-written sources live elsewhere: `.doc/` (product, architecture),
`.claude/rules/` (always-on rules), `.claude/skills/` (on-demand procedures),
`.plan/` (backlog and plans). See `AGENTS.md`.
